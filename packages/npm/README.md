# proofx (npm)

ProofX CLI — Evidence Infrastructure for Software.

## Install

```bash
npm install -g proofx
```

Or use directly in a project:

```bash
npm install --save-dev proofx
npx proofx --version
```

## What happens on install

`postinstall` downloads the correct prebuilt binary for your platform
from [GitHub Releases](https://github.com/EslaM-X/proofx/releases).
No Go toolchain required.

## Supported platforms

| OS    | Architecture |
|-------|-------------|
| macOS | x64, arm64  |
| Linux | x64, arm64  |
| Windows | x64, arm64 |
